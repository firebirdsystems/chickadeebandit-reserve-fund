# Reserve Fund Dashboard

A [Chickadee Bandit](https://chickadeebandit.com/app-library/reserve-fund) app.

Track organization capital reserve funds — balances, goals, deposit/withdrawal ledger, capital project planning, and balance-over-time charts. Board manages; all members can view.

## Features

- Named funds with balances and goals.
- Deposit and withdrawal ledger.
- Capital project planning.
- Balance-over-time charts.
- Board manages; all members view.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-reserve-fund/releases/latest/download/bundle.json
```
